# No documentation yet

This site is scaffolded but carries no generated documentation. The first
section — an API reference built from AnythingLLM's committed OpenAPI spec —
arrives at milestone M2.

## What will be here

Every published page will carry provenance: the source files it was generated
from with their digests, the upstream AnythingLLM version it describes, the
model that drafted it, and the prompt version used. Pages are reviewed by a
human before they appear.

Nothing reaches this site without passing that review gate.

## Why the site exists before the content

The build and deploy path is verified first, on an empty site, so that the
first real page has somewhere working to land. That is milestone M0's exit
criterion.
